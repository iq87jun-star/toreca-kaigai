日本の計算関数(Excel)

セルに =JP. と入力すると関数の一覧が出ます。「範囲も可」の引数に範囲(A2:A100)を渡すと、行ごとにまとめて計算します。

日付を返す関数(WORKDAY・FROM_WAREKI・HOLIDAYS)はシリアル値を返します。セルの表示形式を「日付」にしてください(Excel 標準の WORKDAY と同じです)。 計算はすべて Excel の中で行い、入力した値を外部に送りません。

手取り(2026年度の率)

=JP.TAKEHOME(monthlySalary, [bonus], [age], [prefecture])
月給・賞与から1年間の手取り額を計算します(2026年度の率・会社員・独身で扶養なし)。
  • monthlySalary … 月給(額面・各種手当込み)。範囲も可
  • bonus … 年間の賞与の合計(省略時は0)
  • age … 年齢(40〜64歳は介護保険がかかる。省略時は30)
  • prefecture … 勤務先の協会けんぽの都道府県(省略時は東京都)
例: =JP.TAKEHOME(300000) → 2,876,160
=JP.TAKEHOME_DETAIL(monthlySalary, [bonus], [age], [prefecture])
手取りの内訳(社会保険料・所得税・住民税)を2列の表で返します(2026年度の率)。
  • monthlySalary … 月給(額面・各種手当込み)
  • bonus … 年間の賞与の合計(省略時は0)
  • age … 年齢(40〜64歳は介護保険がかかる。省略時は30)
  • prefecture … 勤務先の協会けんぽの都道府県(省略時は東京都)
例: =JP.TAKEHOME_DETAIL(300000)

求人の給与

=JP.ANNUAL_INCOME(salaryText, [workText], [which])
求人の給与欄の文章から年収の目安を計算します(月給×(12+賞与の月数)、年俸があれば年俸)。
  • salaryText … 給与欄の文章。範囲も可
  • workText … 勤務時間・休日の文章(省略可)
  • which … "min"(下限・省略時)または "max"(上限)
例: =JP.ANNUAL_INCOME("月給25万円～＋賞与年2回（4.5ヶ月分）") → 4,125,000
=JP.HOURLY_EQUIVALENT(salaryText, [workText])
求人の給与欄の文章から、時給に換算した額(下限)を計算します。時給の求人や読めない時は空。
  • salaryText … 給与欄の文章。範囲も可
  • workText … 勤務時間・休日の文章(無ければ1日8時間・年間休日120日と仮定)
例: =JP.HOURLY_EQUIVALENT("月給30万円", "実働8時間 年間休日125日")
=JP.FIXED_OVERTIME(salaryText)
求人の給与欄から固定残業代(みなし残業代)の金額を取り出します。書かれていなければ空。
  • salaryText … 給与欄の文章。範囲も可
例: =JP.FIXED_OVERTIME("月給30万円（固定残業代40時間分・5万円を含む）") → 50,000

金額・物件

=JP.YEN(text)
日本語の金額の書き方を数値にします(例: 1億2000万円 → 120000000)。
  • text … 金額の文字列。範囲も可
例: =JP.YEN("1億2000万円") → 120,000,000
=JP.AREA_M2(text)
面積の書き方を㎡にします(例: 10坪 → 33.06)。数値はそのまま㎡とみなします。
  • text … 面積の文字列。範囲も可
例: =JP.AREA_M2("10坪") → 33.06
=JP.TSUBO_PRICE(price, area)
坪単価(価格または賃料 ÷ 坪数)を計算します。「4,980万円」「70.12㎡」のような書き方も可。
  • price … 価格または賃料。範囲も可
  • area … 面積(数値は㎡)
例: =JP.TSUBO_PRICE("4,980万円", "70.12㎡")
=JP.LOAN_PAYMENT(principal, [ratePercent], [years])
住宅ローンの毎月の返済額(元利均等)を計算します。
  • principal … 借入額(「3,000万円」のような書き方も可)。範囲も可
  • ratePercent … 年利(%・省略時は1)
  • years … 返済期間(年・省略時は35)
例: =JP.LOAN_PAYMENT("3000万円", 1, 35)

和暦・祝日・営業日

=JP.WAREKI(date, [format])
日付を和暦にします(例: 2026/9/24 → 令和8年9月24日)。
  • date … 日付。範囲も可
  • format … "long"(令和8年9月24日・省略時)または "short"(R8.9.24)
例: =JP.WAREKI(A2) → 令和8年9月24日
=JP.FROM_WAREKI(text)
和暦の文字列を日付(シリアル値)にします(例: 令和6年4月1日、R6.4.1、平成元年1月8日)。
  • text … 和暦の文字列。範囲も可
例: =JP.FROM_WAREKI("R6.4.1") → 2024/4/1(表示形式を日付に)
=JP.IS_HOLIDAY(date)
日本の祝日(振替休日・国民の休日を含む)かどうかを返します。
  • date … 日付。範囲も可
例: =JP.IS_HOLIDAY(A2)
=JP.HOLIDAY_NAME(date)
祝日の名前を返します(祝日でなければ空)。
  • date … 日付。範囲も可
例: =JP.HOLIDAY_NAME(A2) → 敬老の日
=JP.IS_BUSINESS_DAY(date, [yearEndClosure], [closedDates])
営業日(土日・祝日・指定した休業日以外)かどうかを返します。
  • date … 日付。範囲も可
  • yearEndClosure … TRUE なら12月29日〜1月3日を休みとして扱う
  • closedDates … 独自の休業日の範囲(省略可)
例: =JP.IS_BUSINESS_DAY(A2, TRUE)
=JP.WORKDAY(date, days, [yearEndClosure], [closedDates])
○営業日後(マイナスなら前)の日付を返します。日本の祝日に対応した WORKDAY です。
  • date … 開始日(この日は数えない)。範囲も可
  • days … 営業日数(マイナスで前へ)
  • yearEndClosure … TRUE なら12月29日〜1月3日を休みとして扱う
  • closedDates … 独自の休業日の範囲(省略可)
例: =JP.WORKDAY(A2, 5) → 5営業日後(表示形式を日付に)
=JP.NETWORKDAYS(startDate, endDate, [yearEndClosure], [closedDates])
期間の営業日数を返します(開始日・終了日を含む)。日本の祝日に対応した NETWORKDAYS です。
  • startDate … 開始日
  • endDate … 終了日
  • yearEndClosure … TRUE なら12月29日〜1月3日を休みとして扱う
  • closedDates … 独自の休業日の範囲(省略可)
例: =JP.NETWORKDAYS(A2, B2)
=JP.HOLIDAYS(year)
その年の祝日の一覧(日付のシリアル値と祝日名の2列)を返します(内閣府の公式データ)。
  • year … 年(例: 2026)
例: =JP.HOLIDAYS(2026)

請求・支払

=JP.PAYMENT_DATE(date, terms, [holidayRule], [closedDates])
支払条件(例: 末締め翌月25日払い)から支払日(シリアル値)を返します。土日・祝日なら前営業日にします。
  • date … 取引日・請求日。範囲も可
  • terms … 支払条件の文章(例: 末締め翌月25日払い、20日締め翌々月末日支払)。行ごとに違う条件なら範囲も可
  • holidayRule … 休日の時: "前"(前営業日・省略時)、"翌"(翌営業日)、"なし"。文章に「翌営業日」とあればそれに従う
  • closedDates … 独自の休業日の範囲(省略可)
例: =JP.PAYMENT_DATE(A2, "末締め翌月25日払い") → 25日が休日なら前営業日(表示形式を日付に)
=JP.WITHHOLDING(amount, [includesTax])
報酬・料金の源泉徴収税額を返します(100万円までは10.21%、超える部分は20.42%。1円未満切り捨て)。
  • amount … 報酬の額(税抜。「10万円」のような書き方も可)。範囲も可
  • includesTax … TRUE なら、消費税を区分していない税込の額として扱う
例: =JP.WITHHOLDING(100000) → 10,210
=JP.IS_VALID_REGNO(number)
インボイスの登録番号(T + 13桁)または法人番号(13桁)が正しい形か(検査用数字が合うか)を返します。登録されているかは国税庁のサイトで確認してください。
  • number … 登録番号または法人番号(全角・ハイフン可)。範囲も可
例: =JP.IS_VALID_REGNO("T7000012050002") → TRUE
=JP.REGNO(number)
登録番号・法人番号を「T + 13桁」の形に整えます(全角・空白・ハイフンを除き、法人番号なら先頭に T)。
  • number … 登録番号または法人番号。範囲も可
例: =JP.REGNO("登録番号：Ｔ７０００－０１２０－５０００２") → T7000012050002
